# ESP32-S31 Avatar Companion

这是一个基于 ESP32-S31 的智能语音设备项目，当前包含设备端固件和 Android 配套 App。

设备端负责屏幕 UI、麦克风采集、WebSocket 对话、TTS 播放、BLE 配网和靠近问候；Android App 负责蓝牙配网、设备绑定和靠近触发。

## 功能介绍

最近给我的 ESP32-S31 设备做了一套配套的 Android App，主要解决两个问题：**更方便地给设备配网**，以及**让设备知道“我靠近了”**。

以前设备配 WiFi，需要在设备屏幕上扫 WiFi、输入密码，操作比较麻烦。现在改成了手机 App 通过 BLE 蓝牙给设备配网：设备上电后先广播蓝牙，手机 App 找到设备后建立连接，完成安全握手，然后把 WiFi 名称和密码发给设备，设备连上 WiFi 后再关闭配网蓝牙，进入正常对话模式。

这里用到的核心技术主要有几个：

1. **BLE 蓝牙配网**  
   手机不用和设备在同一个网络里，也不用设备先联网，只要蓝牙能搜到设备，就可以把 WiFi 信息安全地发过去。

2. **PoP 安全校验**  
   配网时会用一个验证码做安全握手，避免别人随便连上设备给它乱配网。

3. **设备绑定 Token**  
   第一次绑定设备时，App 会生成一个 token 保存起来。以后只有绑定过的手机，才能触发设备的“靠近问候”，避免任何人靠近都能唤醒设备。

4. **Presence Service 靠近感知**  
   设备联网后会开放一个 BLE 服务，App 在后台扫描到绑定设备并判断距离足够近时，会发送一个 `nearby` 事件。设备收到后主动连接 WebSocket，让 AI 主动打招呼。

5. **WebSocket 实时对话链路**  
   设备通过 WebSocket 和服务端保持通信，上传麦克风音频，接收语音识别结果和 TTS 语音回复，实现自然对话。

这么做的意义是：设备不再只是一个“等人操作”的硬件，而是可以更自然地融入使用场景。用户第一次用 App 配好网、绑定设备后，后面只要带着手机靠近，设备就能主动问候，不需要每次点按钮、不需要重新连接蓝牙、不需要手动唤醒。

我觉得这个体验很接近未来智能硬件应该有的状态：

**第一次配置尽量简单，后续使用尽量无感。**

现在这套系统已经实现了：

- Android App 蓝牙配网
- 手机绑定设备
- token 校验
- 手机靠近后自动触发设备问候
- ESP32-S31 屏幕对话界面
- 麦克风语音上传
- WebSocket AI 对话
- TTS 播放
- 鳄鱼数字人头像显示

下一步准备继续优化后台扫描稳定性、设备解绑流程、配网结果页，以及更完整的产品化交互。
