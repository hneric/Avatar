#### ⚠️ I2S 引脚命名混淆（耗时最长）
```
原理图上标注 I2S_DSDIN=GPIO5, I2S_SDOUT=GPIO6 (ES8389 视角)
ESP32 I2S 驱动配置: .dout=GPIO5, .din=GPIO6 (ESP32 视角)

错误理解: 把 ESP32 的 DOUT 设成了 GPIO6
         = 数据发到了错误的引脚上，Codec 收不到

正确配置: 
  .dout = GPIO_NUM_5  (ESP32 发数据 → Codec DIN)
  .din  = GPIO_NUM_6  (ESP32 收数据 ← Codec DOUT)
```

#### ES8389 关键配置
| 参数 | 值 | 说明 |
|------|-----|------|
| `use_mclk` | `false` | Codec 自己从 BCLK 生成内部时钟 |
| `master_mode` | `false` | Slave 模式 |
| `codec_mode` | `ESP_CODEC_DEV_WORK_MODE_DAC` | 仅 DAC 输出 |
| `dev_type` | `ESP_CODEC_DEV_TYPE_OUT` | 仅输出 |
| 采样率 | **48000 Hz** | 48kHz 立体声 |
| PA 控制 | **GPIO7** | 功放使能，高电平有效 |

### 4. 数据库存问题及修复记录

#### LCD RGB 面板
| 问题 | 原因 | 修复 |
|------|------|------|
| 帧缓冲分配失败 | PSRAM 未启用，(800×480×2=768KB > 421KB RAM) | `sdkconfig.defaults` 加 `CONFIG_SPIRAM=y` |
| `lvgl_port_add_disp_rgb` 失败 | 组件仅支持 ESP32-S3 和 P4 | 改用 `lvgl_port_add_disp()` |
| `lvgl_port_add_disp` `io_handle` 断言 | RGB 面板没有 IO handle | 改用 `lvgl_port_add_disp_rgb()` + 修改组件源码 +S31 |
| `avoid_tearing` 帧缓冲获取失败 | 代码只支持 S3/P4 | 禁用 `avoid_tearing` |

#### 音频
| 问题 | 原因 | 修复 |
|------|------|------|
| `i2s_channel_disable` 未启用 | I2S 通道状态管理混乱 | 去掉手动 `i2s_channel_enable`（让 codec_dev 管理） |
| 无声音、数据写入成功 | **I2S 引脚反了** | `dout=GPIO5, din=GPIO6` |
| 按钮按下栈溢出 | `int16_t buf[48000]` (96KB) 在 6KB 栈上 | 改为 `heap_caps_malloc` |
| LVGL 锁重入 | 在已持锁的回调中再次加锁 | 去掉回调中的 `_lock_acquire` |
