# ESP32-S31-Korvo-1 开发环境说明

## 1. 激活 ESP-IDF master 环境

每次打开新 PowerShell 终端，先执行：

```powershell
cd C:\Users\WIN10\esp\esp-idf-master
.\export.ps1
```

如果 PowerShell 提示禁止运行脚本，可以只对当前窗口临时放开：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
cd C:\Users\WIN10\esp\esp-idf-master
.\export.ps1
```

如果 `idf.py` 提示 Unicode/编码问题，先执行：

```powershell
chcp 65001
$env:PYTHONUTF8="1"
```

## 2. 当前主线工程

当前建议优先开发精简版固件：

```powershell
cd d:\code\esps31\firmware
idf.py build
```

首次设置目标时执行：

```powershell
idf.py --preview set-target esp32s31
```

烧录和监控：

```powershell
idf.py -p COMx flash
idf.py -p COMx monitor
```

## 3. WiFi / WebSocket 配置

固件启动后会显示 WiFi 配网页：

- 点击 `Scan` 扫描附近 WiFi
- 点击左侧列表中的 SSID
- 在密码框输入密码
- 点击 `Connect`
- 连接成功后底部状态栏会显示 `WiFi connected`，并启动 WebSocket

WebSocket 后端地址仍建议先通过配置菜单填写：

```powershell
idf.py menuconfig
```

配置位置：

```text
Korvo-1 Network
```

需要填写：

- `WebSocket host`
- `WebSocket port`
- `WebSocket path`
- `WebSocket authorization token`，如果后端需要鉴权

`WiFi SSID` 和 `WiFi password` 可以留空，优先使用屏幕上的 WiFi 选择界面。

当前服务器配置已经确认：

```text
WebSocket host = 120.25.213.109
WebSocket port = 8989
WebSocket path = /xiaozhi/v1/
WebSocket authorization token = 留空
```

服务器端 `auth.enable=false`，所以不需要填写 token。

## 4. xiaozhi-esp32 目录用途

`d:\code\esps31\xiaozhi-esp32` 当前主要作为原始项目参考和后续回迁目标：

```powershell
cd d:\code\esps31\xiaozhi-esp32
```

由于 ESP32-S31 还是预览目标，完整 `xiaozhi-esp32` 直接编译会继续遇到第三方组件适配问题，例如 `esp-sr`、`esp_audio_codec`、`esp_video`、`esp32-camera` 等。因此当前先在 `firmware` 目录完成：

- LCD 800x480 显示
- GT1151 触摸
- ES8389 音频 I2S 通路
- WiFi + WebSocket
- 与 xiaozhi 后端直接通信

## 5. I2S 引脚方向

原理图里的 `I2S_DSDIN` 和 `I2S_SDOUT` 是 ES8389 Codec 视角：

| 原理图标注 | GPIO | ES8389 视角 | ESP32 I2S 配置 |
|---|---:|---|---|
| `I2S_DSDIN` | GPIO5 | 数据进入 Codec | `.dout` |
| `I2S_SDOUT` | GPIO6 | 数据离开 Codec | `.din` |

正确连接关系：

```text
ESP32 dout -> Codec DSDIN  (GPIO5)
ESP32 din  <- Codec SDOUT  (GPIO6)
```
