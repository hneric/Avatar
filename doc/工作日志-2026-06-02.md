## 图片转换和设置方式

### 1. 当前推荐源图

当前推荐使用“无嘴小鳄鱼头像”：

```text
tools/avatar/croc_source_nomouth.png
```

原因：

- 原图没有嘴巴，不会和程序生成的嘴型冲突。
- speaking 状态叠加嘴型时，不会出现旧嘴巴、牙齿、黄线重复。
- idle/listening 可以由程序生成基础闭嘴弧线。

### 2. 生成命令

在工程根目录执行：

```powershell
cd D:\code\esps31
powershell -ExecutionPolicy Bypass -File tools\avatar\make_croc_avatar_assets.ps1 -Src tools\avatar\croc_source_nomouth.png -Profile head_nomouth
```

输出文件：

```text
firmware/main/avatar_assets/croc_avatar_assets.c
firmware/main/avatar_assets/croc_avatar_assets.h
firmware/main/avatar_assets/preview/*.png
```

其中 `preview` 目录用于肉眼检查生成效果。

### 3. 当前头像 profile 参数

脚本里新增了 `head_nomouth` profile：

```powershell
head_nomouth = @{
    cover_mouth = $false
    mouth_patch = @(48, 112, 132, 152)
    mouth_center = @(90, 138)
    left_eye_box = @(35, 54, 74, 98)
    right_eye_box = @(106, 54, 145, 98)
    mouth_scale = 0.82
}
```

说明：

- `mouth_center` 是嘴巴中心点，按 180x180 标准坐标描述。
- 当前最终显示尺寸是 270x270，所以脚本会自动按比例放大。
- 如果嘴巴还是偏高，后续可以把 `mouth_center` 的 y 从 `138` 调到 `142`。
- 如果嘴巴偏低，就调回 `134` 或 `136`。
- `mouth_scale` 控制所有嘴型整体大小。

### 4. 棋盘格背景处理

用户提供的头像可能带有“看起来像透明”的棋盘格，但实际是图片像素。

脚本里增加了背景清理：

```powershell
Remove-CheckerboardBackground
```

处理方式：

- 从图片边缘开始 flood-fill。
- 只清理边缘连通的浅灰/白色棋盘格。
- 不会误删眼睛、牙齿等主体内部白色区域。

如果以后图片本身已经是标准透明 PNG，也可以继续使用当前脚本；透明区域会保留。

### 5. LVGL 图片格式

生成的 C 资源使用：

```c
LV_COLOR_FORMAT_RGB565A8
```

数据布局：

```text
RGB565 像素数据
Alpha 平面数据
```

注意点：

- 之前出现过“整块方块/花屏”的问题，原因是 RGB565 和 Alpha 数据排布不对。
- 当前脚本已经修正为 LVGL 需要的格式：先写所有 RGB565，再写完整 Alpha。
- 不需要运行时 PNG 解码，直接编进固件。

### 7. 固件侧叠加方式

固件中每个图层都是一个 `lv_image`。

基础头像：

```c
avatar_img_base = lv_image_create(scr);
avatar_set_image_layer(avatar_img_base, &croc_avatar_base_layer);
```

嘴巴：

```c
avatar_img_mouth = lv_image_create(scr);
avatar_set_image_layer(avatar_img_mouth, &croc_avatar_mouth_0_layer);
```

眨眼：

```c
avatar_img_blink = lv_image_create(scr);
avatar_set_image_layer(avatar_img_blink, &croc_avatar_blink_layer);
```

表情：

```c
avatar_img_expression = lv_image_create(scr);
avatar_set_image_layer(avatar_img_expression, &croc_avatar_thinking_layer);
```

图层位置由生成脚本写入：

```c
typedef struct {
    const lv_image_dsc_t *img;
    int16_t x;
    int16_t y;
    int16_t w;
    int16_t h;
} croc_avatar_layer_t;
```

固件使用统一偏移：

```c
#define AVATAR_IMAGE_X 40
#define AVATAR_IMAGE_Y 92
```

实际显示位置：

```c
AVATAR_IMAGE_X + layer->x
AVATAR_IMAGE_Y + layer->y
```

这样每个图层都可以单独裁剪，减少固件体积，同时仍能准确叠加。

### 8. 动画状态

当前头像状态：

```text
Idle:      mouth_0
Listening: mouth_0
Thinking:  mouth_0 + thinking layer
Speaking:  根据 TTS RMS/Peak 在 mouth_0/1/2/3 之间切换
```

speaking 逻辑：

```c
int open = MIN(MAX((rms - 220) / 80, 0), 22);
int peak_open = MIN(MAX((peak - 1400) / 900, 0), 10);
open = MAX(open, peak_open);
```

说明：

- 音量很小时保持 `mouth_0`。
- 小音量使用 `mouth_1`。
- 中等音量在 `mouth_2` / `mouth_3` 间切换。
- 当前避免使用过大的 `mouth_4`，防止嘴巴过大。

### 9. 资源体积

当前生成后的头像资源：

```text
firmware/main/avatar_assets/croc_avatar_assets.c 约 1.64 MB
firmware/main/avatar_assets/croc_avatar_assets.h 约 1 KB
```

由于使用了 Alpha 裁剪：

- base 保持完整头像。
- mouth/blink/thinking 只保留有内容的最小矩形区域。
- 比全画布每层都 270x270 明显节省空间。
