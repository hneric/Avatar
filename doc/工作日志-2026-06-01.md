### 8. 修复 WebSocket 发送崩溃

问题：

WiFi 连接后，WebSocket 连接成功，但发送 hello 时重启：

```text
Guru Meditation Error: Core 0 panic'ed (Store access fault)
_ws_write at transport_ws.c:451
buffer[i] = (buffer[i] ^ mask[i % 4]);
websocket_client.c:62
```

原因：

`esp_transport_ws_send_raw()` 会对客户端 payload 做 mask，并且会原地修改传入 buffer。之前传入的是只读字符串常量：

```c
const char *hello = "...";
```

修复：

```c
char hello[] = "...";
```
